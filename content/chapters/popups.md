# Всплывающие окна: CSS-анатомия

[Оглавление](../README.md) · [Правила агента](../AGENTS.md)

## Три роли

`core-popup-box` — фиксированный контейнер окна на весь viewport, z-index 200, внутренний отступ 16 px и вертикальная прокрутка. По умолчанию он скрыт через visibility и не принимает pointer-events. `core-popup-overlay` — отдельный затемняющий слой. `core-popup` — само окно с переходами opacity/transform.

Класс **`opened` на `core-popup-box`** включает видимое состояние. Это исключение из префикса `core-`, подтверждённое селекторами CSS. Не заменяйте его на выдуманное `core-opened`.

У `core-popup` фон и скругление в этой сборке закомментированы. Для оформленного окна добавьте `core-card`, `core-bg` и нужный радиус явно. Старый `core-popup-zero` удалён: для окна без поверхности не добавляйте оформляющие классы.

## Позиция

`core-popup-center` фиксирует окно по центру. `core-popup-left/right` — боковые панели шириной 465 px и высотой 100%; при ≤720 px их ширина становится `calc(100% - var(--s-10x))`. `core-popup-top/bottom` прижимают окно к верхней/нижней стороне, используют собственную анимацию смещения. Выберите одну позицию, не соединяйте несколько направлений.

## Размеры

Для обычного окна `core-popup-xs/s/m/l/xl` означают соответственно `min(300/450/600/750/1000px, 100%)`. При ≤997 px small становится 360 px, medium — 465 px, large и extra-large — 100%. При ≤720 px s/m/l/xl занимают 100%. XS сохраняет свою формулу.

Размеры и боковые позиции могут одновременно назначать width, поэтому их сочетание необходимо проверять по каскаду, а не трактовать как независимые параметры. Фиксированная центральная позиция также требует проверки высокого контента на низком экране.

## Не путайте CSS-состояние с доступным диалогом

CSS задаёт позицию и видимость. [PopupManager](js-popup.md) добавляет стек, Escape, оверлей, историю, `inert` закрытых/нижних окон и ловушку Tab. Он не делает весь фоновый документ inert и не назначает начальный фокус, `role` или доступное имя.

Используйте `role="dialog"`, `aria-modal="true"`, `aria-labelledby` и явный перенос фокуса после `popup:activate`. Для диалога, которому нужна полная изоляция фона, обеспечьте её в коде приложения. Пример E59 ниже показывает только CSS-анатомию, не работу менеджера.

### E59. Центральное окно: CSS-состояние

Статический открытый блок. Рабочий диалог с кнопками и обработчиком приведён в разделе PopupManager.

```html
<div class="core-popup-box opened">
  <div class="core-popup-overlay" aria-hidden="true"></div>
  <section class="core-popup core-popup-center core-popup-s core-card core-bg core-col" aria-label="Пример всплывающего блока">
    <h2 class="core-text core-text-l core-text-bold">Материалы сохранены</h2>
    <p class="core-text">Расположение, поверхность и состояние opened.</p>
    <p class="core-text core-text-s">Статический пример без управления диалогом.</p>
  </section>
</div>
```
