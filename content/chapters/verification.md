# Источники и проверки

[Оглавление](../README.md) · [Правила агента](../AGENTS.md)

## Проверенная версия

21.09.2026 проверены 32 файла из `latest/` и 32 файла из `v185/`: CSS, три темы, десять функциональных JS-модулей, importmap, их минифицированные варианты, шаблон и readme. В репозитории сохранены только SHA-256, размеры и исходные адреса в [манифесте](../reference/source-manifest.json). Локальные копии Core удалены; сборка и проверки читают файлы непосредственно с CDN.

У 29 файлов latest и v185 одинаковые байты. `.readme.html`, `importmap.js` и `importmap.min.js` отличаются адресами канала. Нельзя считать latest и v185 полностью одинаковыми.

Все 17 исходников v182, перечисленных в старом манифесте, скачаны повторно и совпали с его SHA-256. По сравнению с v182 изменились CSS, importmap и readme. Десять функциональных JS-модулей и три темы не изменились. Их подробное описание из первоначального аудита сохранено; новые ограничения совместимости JS/CSS отмечены отдельно.

## Что изменилось в v185

- Иконки `shevron` переименованы в `chevron`; именованные размеры задаются на элементе.
- Подчёркивание шапки таблицы: `core-table-head-underline`.
- Адаптивные ограничения роста: `t-core-nogrow/noshrink`, `m-core-nogrow/noshrink`.
- Добавлен `--s-170x`; исправлены общий селектор заголовка, цвет radio-group и несколько opacity-деклараций.
- Анимации используют `core-animate:*`. CollapseManager, SliderManager и обработчик копирования FieldManager всё ещё используют старые имена. Для первых двух доступны настройки; особенности FieldManager описаны в его разделе.
- У padding удалён fallback `0`; у позиционирования исправлены разделители, но смешаны некоторые t/m-алиасы.
- Карта latest теперь ведёт на latest.

Подробности, включая оставшиеся проблемы, — в [реестре ограничений](pitfalls.md).

## Справочники и сборка

При сборке PostCSS разбирает четыре CSS-файла CDN v185 после проверки их SHA-256: **2600 явных классов, 481 имя custom properties, 19 регистраций @property**. Каталоги сохраняют файл, строку и область действия. Это исходные декларации, а не обещание допустимости каждого вычисленного значения.

Редактируемые источники лежат в `content/`: тексты в `chapters/`, примеры и манифесты в `reference/`, поведение оболочки в `viewer/`. `npm run build` очищает `docs/`, копирует публичные источники и генерирует справочники, индекс классов и HTML. Результат содержит 42 Markdown-главы и 82 примера; `docs/` исключён из Git. Оформление оболочки и примеров полностью задаётся Core и темой NK: собственных CSS-правил нет. Штатные переменные `--w`, `--h` и `--tr` управляют размером и масштабированием iframe. Действия оболочки реализованы отдельным vanilla JS.

## Текущие проверки

В репозитории находятся проверки `npm test`, `npm run test:browser` и `npm run test:layout`. Они проверяют целостность источников, отсутствие собственного CSS, соответствие примеров Markdown, работу оболочки и выбранные действия в живых iframe. Контрактные тесты сверяют 32 ответа v185 с SHA-256 манифеста и проверяют доступность 32 файлов latest. Расхождение latest с прежними хешами выводится в диагностике и не меняет принятую версию документации. Браузерные проверки мануала загружают настоящий CDN latest, включая iframe и ESM; отдельная проверка точных CSS-контрактов документации загружает v185 с CDN. Локальной подмены нет. Для проверки ошибки и восстановления запросы временно блокируются, затем снова разрешаются в сеть. Проверяются ширины 390/720/721/997/998/1440 px, сохранение ввода при смене темы и главы, reduced motion, ошибка CDN и повторная загрузка.

Оболочка дополнительно проверена на сохранение компактной шапки и боковой навигации при прокрутке, мобильное меню без сдвига статьи, закрытие по фону/Escape/выбору раздела и удержание клавиатурного фокуса. Парные снимки исходного и восстановленного мануала сравнивались отдельно: начало главы, пример, раскрытый код, мобильное меню и тёмная тема. Эти проверки не заменяют оценку остальных компонентов Core.

`npm run check:upstream` по запросу владельца сравнивает каталог версий, список файлов и все SHA-256 с манифестом, ничего не изменяя; при расхождении возвращает код 2. На 23.09.2026 каталог содержит v190; в latest изменены core.css, theme-ss.css и их минифицированные варианты. Обычные сборки и тесты не принимают новую версию автоматически. Недоступность CDN или изменение проверяемого файла v185 останавливает публикацию; диагностика изменений latest сама по себе её не блокирует.

Старые отчёты о 35 CSS-, 26 UI- и 74 JS-проверках сохранены в исходном коммите v182. Эти числа не являются результатом текущего прогона и не суммируются с новыми проверками.

## Границы достоверности

Запуск всех примеров не означает перебор всех состояний каждого компонента. Браузерный стенд использует Chromium; Safari, Firefox и скринридеры не проверялись. Браузер загружает внешние шрифты штатной темы; это не является полной проверкой всех шрифтов и платформ. Сетевые сбои могут остановить проверки, даже если исходники документации не менялись.

Не проверяются реальные серверные endpoint, Telegram SDK, успешное сохранение FormManager в localStorage/cookie и полная эквивалентность минифицированных файлов. Фреймворк не исправляется скрытыми патчами мануала. Latest остаётся изменяемым; анализ и принятие новой версии выполняются только по запросу владельца.
