# CORE docs

Документация фреймворка Core: HTML-мануал для человека и Markdown-руководство для агента.

## Состояние

Подготовлена инфраструктура отдельного проекта. Готовый мануал, примеры и тема из предыдущих обсуждений ещё не перенесены. Следующий этап — получить актуальный комплект, проверить его происхождение и сохранить исходное состояние.

## Назначение

Документация должна объяснять классы и переменные Core, вложенность, наследование, композицию, адаптивность, темы и JavaScript. Примеры должны показывать подтверждённые возможности фреймворка; дополнительный CSS обозначается отдельно.

Репозиторий содержит документацию. Исходный Core развивается отдельно.

## Работа с проектом

Перед изменениями прочитайте [AGENTS.md](AGENTS.md). После импорта комплекта здесь появятся подтверждённые команды просмотра, сборки и проверки. На этапе инфраструктуры установка зависимостей не требуется.
