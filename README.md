42 раздела, 82 примера. Проверенный снимок — **Core v185 от 21 сентября 2026 года**. Оболочка и примеры оформлены штатными классами Core и темой NK, без собственных CSS-правил. Значения `--w`, `--h` и `--tr` задают размеры и масштаб примеров через API Core.

Откройте `manual/index.html` в браузере. Сам файл статический; оформление, шрифты и живые примеры требуют сети. Runtime использует CDN `latest`, поэтому его содержимое со временем может отличаться от проверенного снимка.

## Редактирование

- `manual/docs/` — тексты глав.
- `manual/reference/examples.json` — разметка и JavaScript примеров. При изменении примера обновите соответствующий блок Markdown; проверка сверяет их.
- `manual/chapters.json` — порядок, группы и короткие названия разделов.
- `manual/viewer/app.js` — поведение оболочки, без собственного оформления.
- `tools/build.mjs` — сборка одного HTML, включая данные и просмотрщик.
- `upstream/latest/`, `upstream/v185/` — неизменённые скачанные файлы для аудита и тестов. Они не подменяют CDN в мануале.

Node.js 22 или новее нужен только для разработки. Зависимости закреплены в lockfile: Marked разбирает Markdown, PostCSS и selector-parser строят справочники, Playwright проверяет настоящий браузер. Runtime не использует npm-пакеты.

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
npm run serve
```

Локальный адрес: `http://127.0.0.1:4173/manual/index.html`. Тесты используют Chromium, совместимый с закреплённым Playwright. Команда установки браузера нужна один раз после `npm ci`. Перехват запросов из sandbox iframe проверяется явно: прогон не считается воспроизводимым, если тестовый браузер загружает их напрямую из сети.

`node tools/references.mjs` пересобирает справочники из снимка. `node tests/browser.mjs --live` отдельно проверяет реальный CDN; основной браузерный прогон получает точные байты снимка через перехват запросов.

## Обновление Core

Проверять новые версии **только по запросу владельца**:

```sh
npm run check:upstream
```

Команда ничего не меняет: сравнивает каталог версий, список файлов latest и SHA-256 каждого файла со снимком. Код выхода: 0 — совпадает, 2 — есть изменения, 1 — ошибка проверки. Скачивание новой версии, изменение документации и публикация требуют отдельного осмысленного обновления.

Исходный комплект v182 сохранён без изменений в коммите `e9de771`. Манифест содержит его контрольные суммы и результаты сверки v182 → latest/v185. Публикация сайта не настроена.
