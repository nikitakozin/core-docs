# Core — документация

[Открыть мануал](docs/index.html) · [Markdown для агента](docs/AGENTS.md) · [Источники и проверки](docs/docs/verification.md)

42 раздела, 82 примера. Проверенный снимок — **Core v185 от 21 сентября 2026 года**. Оболочка и примеры оформлены штатными классами Core и темой NK, без собственных CSS-правил. Штатные параметры типографики задают масштаб текста оболочки; `--w`, `--h` и `--tr` — размеры и масштаб примеров через API Core.

Откройте `docs/index.html` в браузере. Сам файл статический; оформление, шрифты и живые примеры требуют сети. Runtime использует CDN `latest`, поэтому его содержимое со временем может отличаться от проверенного снимка.

Тёмная боковая навигация сохраняет группы и подразделы; шапка с поиском закреплена. На экранах до 997 px разделы открываются поверх статьи. Меню закрывается по Escape, нажатию на фон или выбору раздела. Поиск доступен по ⌘K / Ctrl+K.

У примера семь кнопок ширины: Auto, 390, 720, 721, 997, 998 и 1200 px. Код раскрывается под результатом; обычные фрагменты инструкций видимы сразу. Тема, ввод и выбранная ширина сохраняются при переключении глав в открытом мануале.

## Редактирование

- `docs/docs/` — тексты глав.
- `docs/reference/examples.json` — разметка и JavaScript примеров. При изменении примера обновите соответствующий блок Markdown; проверка сверяет их.
- `docs/chapters.json` — порядок, группы и короткие названия разделов.
- `docs/viewer/app.js` — поведение оболочки, без собственного оформления.
- `tools/build.mjs` — сборка одного HTML, включая данные и просмотрщик.
- `upstream/latest/`, `upstream/v185/` — неизменённые скачанные файлы для аудита и тестов. Они не подменяют CDN в мануале.

Node.js 22 или новее нужен только для разработки. Зависимости закреплены в lockfile: Marked разбирает Markdown, PostCSS и selector-parser строят справочники, Playwright проверяет настоящий браузер. Runtime не использует npm-пакеты.

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
npm run test:layout
npm run serve
```

Локальный адрес: `http://127.0.0.1:4173/docs/index.html`. Тесты используют Chromium, совместимый с закреплённым Playwright. Команда установки браузера нужна один раз после `npm ci`. Перехват запросов из sandbox iframe проверяется явно: прогон не считается воспроизводимым, если тестовый браузер загружает их напрямую из сети.

`npm run test:layout` проверяет компактность шапки, неподвижность боковой панели, меню без сдвига статьи, клавиатурный фокус и структуру примеров на граничных ширинах. Визуальную аккуратность дополнительно проверяйте по парным снимкам: функциональный прогон её не доказывает.

`node tools/references.mjs` пересобирает справочники из снимка. `node tests/browser.mjs --live` отдельно проверяет реальный CDN; основной браузерный прогон получает точные байты снимка через перехват запросов.

## Обновление Core

Проверять новые версии **только по запросу владельца**:

```sh
npm run check:upstream
```

Команда ничего не меняет: сравнивает каталог версий, список файлов latest и SHA-256 каждого файла со снимком. Код выхода: 0 — совпадает, 2 — есть изменения, 1 — ошибка проверки. Скачивание новой версии, изменение документации и публикация требуют отдельного осмысленного обновления.

Исходный комплект v182 сохранён без изменений в коммите `e9de771`. Манифест содержит его контрольные суммы и результаты сверки v182 → latest/v185. Публикация сайта не настроена.
