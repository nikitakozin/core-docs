Подключение и использование

Core создан таким образом, чтобы не конфликтовать с другими библиотеками. Поэтому он может быть как основным на сайте, так и локальным для отдельных элементов.

Для начала достаточно подключить на страницу:

<link rel="stylesheet" href="https://cdn.sdelal.tech/core/latest/core.min.css">

Если на странице уже есть другие библиотеки или js, которые переопределяют стили, изолируйте core-элементы с помощью класса .core-solo:

// Локально
<div class="core-solo">
	// Все core-элементы внутри перебьют стили других библиотек
</div>

// Или на body
<body class="core-solo">
	// Все core-элементы внутри перебьют стили других библиотек
</body>

Основа фреймворка — контейнеры

Контейнеры в core — это «коробки», в которых группируются элементы страницы. Страница целиком состоит из «коробок», вложенных друг в друга.

В контейнер нужно помещать все что соединяется между собой: иконка с текстом, блок с блоком, набор картинок, список карточек и т.п.

Контент

Фреймворк написан таким образом, чтобы элементы ничего не наследовали без добавления класса.

.core-content является исключением — помещённые в него элементы html автоматически выравниваются и принимают стили core, образуя готовую верстку.

<div class="core-content">
	<h1>Заголовок H1</h1>
	<p>Текст</p>
</div>

Заголовок H1

Текст

Без .core-content та же самая верстка выглядела бы так:

<div class="core-col core-g-10x">
	<h1 class="core-h1">Заголовок H1</h1>
	<p class="core-text">Текст</p>
</div>

Заголовок H1

Текст

Контент может иметь три размера: .core-content-s, .core-content-m и .core-content-l


// Уменьшенный
<div class="core-content core-content-s">
	<h1>Заголовок H1</h1>
	<p>Текст</p>
</div>

// Увеличенный
<div class="core-content core-content-l">
	<h1>Заголовок H1</h1>
	<p>Текст</p>
</div>

Модификаторы

Модификаторы позволяют настроить точно отношение элементов внутри контейнеров: задать отступы, ширины, расстояния.

Благодаря гибкой системе модификаторов, колонки, строки и сетки позволяют построить любые части интерфейса: от маленьких карточек до дашбордов

Адаптивность

Чтобы применить отступ на мобилке или планшете, нужно добавить к классу приставку .p-... или .m-...:

  • .core-g-...x — для десктопа
  • .t-core-g-...x — для планшетов
  • .m-core-g-...x — для мобилки
// Так на всех разрешениях применится 0x
<div class="core-row core-g-0x"></div>

// А так на десктопе 0x, на планшете 10x, а на мобилке 2x
<div class="core-row core-g-0x t-core-g-10x m-core-g-2x"></div>

Потомки могут использовать gap контейнера

Все потомки контейнеров и модификатора .core-g-...x имеют переменную --parent-gap:

.core-g-1x > *, 
.core-solo .core-g-1x > * { 
	--parent-gap: var(--s-1x)
}

Это позволяет потомкам использовать gap родителя для определения нужной ширины. Например, чтобы потомок занял 1/3 ширины родителя:

// 3 — количество колонок родителя, 
// По такой формуле потомок займет 1 колонку
width: calc((100% - ((3 - 1) * var(--parent-gap))) / 3);

Создать свое значение

Если не хватает значений по-умолчанию, создайте своё так. Например для 13x:

  1. Добавьте переменную: 
    :root {
	--s-13x: calc(var(--unit) * 13);
}
  2. Создайте класс: 
    .core-g-13x, .core-solo .core-g-13x { 
	gap: var(--s-13x)  
}
  3. Добавьте паременную для дочерних элементов — так они будут знать какой gap у родителя и могут подстроиться под него: 
    .core-g-13x > *, 
.core-solo .core-g-13x > * { 
	--parent-gap: var(--s-13x)
}
  4. Опционально создайте классы для планшета и мобилки: .t-core-g-13x и .m-core-g-13x.
