# Источники и проверки

[Оглавление](../README.md) · [Правила агента](../AGENTS.md)

## Основание документации

Проверен пользовательский `core.zip` от 20.09.2026: 17 файлов — `core.css`, три темы, десять функциональных JS-модулей, `importmap.js`, шаблон и readme. В исходном пакете указан v182. SHA-256 архива и каждого файла — в [манифесте](../reference/source-manifest.json).

Прочитаны все 11 JS-файлов, включая карту импортов. Для десяти модулей описаны экспорты, запуск, зависимости, DOM-контракт, API, события и ограничения. Исходные Core-файлы не исправлялись и в комплект документации не включены.

## CSS и справочники

Разобраны четыре CSS-файла: 2648 явных имён классов, 480 разных имён custom properties, 19 регистраций @property. Каталоги сохраняют область действия и строку исходника. Отсутствие ошибок разбора CSS не доказывает допустимость каждого вычисленного значения; известные ошибки отдельно перечислены в [реестре](pitfalls.md).

Выполнены 35 браузерных проверок CSS: брейкпоинты 390/720/721/997/998/1200 px, вложенные сетки, gap дробных колонок, локальная шкала, типографика, чёрная палитра, формы, таблица-карточки и области SS. Отдельно подтверждено: core-text-l не меняет text-align.

## Примеры и оболочка

Все 82 демонстрации прошли проверку загрузки настоящих правил Core; восемь новых интерактивных примеров также загрузили нужные JS-модули. Это проверка запуска, не перебор всех состояний каждого примера.

Пройдены 26 проверок оболочки и выбранных действий: навигация, подменю, поиск, мобильное меню, ширины iframe, смена темы без потери состояния, счётчик, события, ресурс, числовое поле и диалог.

Страницы и srcdoc подавались тестовым API Chromium. Запросы к CDN в этих тестах получали **неизменённые байты из пользовательского архива**, а не тестовую реализацию Core. Автоматическую загрузку по настоящей сети этот прогон не подтверждает.

## JavaScript

Пройдены 74 проверки методов и сценариев десяти модулей: подписки, очередь событий, дедупликация и устаревшие результаты, навигация, коллапсы, числовые поля, слайдер, silent-диалог, отмена анимаций, сбор формы и veto отправки.

Ограничения двух стендов: NavigationManager проверялся через native History API на about:blank с hash, не через маршруты реального сайта. FormManager проверял сбор/отправку на настоящих DOM-полях с учебным ответом fetch; недоступность Storage в непрозрачном origin проверена как ошибка. Успешное сохранение localStorage/cookie и полный запуск формы в обычном HTTP(S)-origin здесь не проверялись.

## Чего проверка не подтверждает

Текущий ответ живого CDN не сверялся с архивом. В примерах остаются URL `https://cdn.sdelal.tech/core/latest/`; эта версия может измениться. Минифицированных вариантов нет в исходном архиве, поэтому их равенство не заявляется.

Не выполнялись проверки Safari/Firefox, скринридеров, внешних шрифтов, Telegram SDK и реальных серверных endpoint. Настоящие шрифтовые файлы не подменялись и не включены в комплект. Контраст, фокус и жизненный цикл проверяйте в конкретном продукте.

## Целостность комплекта

HTML и Markdown используют одинаковые тексты и примеры. Проверяются внутренние ссылки, уникальные якоря, имена классов в демонстрациях, адреса ассетов и отсутствие старых сборок, тестовых подмен и файлов шрифтов. Машинные источники — [CDN-карта](../reference/cdn.json), [классы](../reference/classes.json), [токены](../reference/tokens.json), [JS](../reference/javascript.json).
