# Ограничения и реестр рисков

[Оглавление](../README.md) · [Правила агента](../AGENTS.md)

## Как читать реестр

Ниже — особенности и дефекты исходников из `core.zip`. Они не исправлены скрытым CSS или JS мануала. Указанное ограничение относится к конкретному селектору или методу, не ко всему компоненту. Результаты браузерных сценариев — в [проверках](verification.md).

## P01. Размер текста не является выравниванием

`core-text-l` задаёт размер large, без text-align. Для выравнивания используйте `core-text-left`, `core-text-right` или `core-text-center`; короткие c/r отсутствуют. [Типографика](typography.md).

## P02. Точное совпадение `class="core-h"`

Общее правило заголовка содержит `[class="core-h"]`, а не `.core-h`. Добавление второго класса меняет совпадение с этим селектором. Размерные `core-h1`…`core-h6` работают через переменные и не всегда компенсируют отсутствие общего правила. Для предсказуемого результата используйте `core-text` как основание и явные размер/вес. [Типографика](typography.md).

## P03. Локальный `--x` не масштабирует всё поддерево

Вычисленные выше алиасы наследуются уже разрешёнными, а `--x` дополнительно зарегистрирован как ненаследуемый и используется в геометрии. Меняйте основу на корне либо используйте конкретные токены/модификаторы. [Наследование](inheritance.md).

## P04. Направленный padding затрагивает остальные стороны

Общий селектор padding совпадает с направленным именем и использует fallback ноль. Добавляйте явный общий `core-p-*`, когда необходимо сохранить остальные отступы карточки. [Отступы](spacing.md).

## P05. Именованный размер иконки сильнее адаптивного числа

Именованные размеры назначены псевдоэлементу, числовые — самому узлу. Локальная переменная псевдоэлемента перекрывает наследование с узла. Для адаптива используйте числовую основу. [Иконки](icons.md).

## P06. Вложенная сетка может унаследовать треки

Основание использует `--grid-cols`, не превращая его в автоматически локальный параметр. У новой вложенной сетки задавайте собственное число колонок. Аналогично не оставляйте без внимания наследуемый счётчик `--c` дробных flex-элементов. [Компоновки](layout.md).

## P07. `core-j-ch` требует передачи gap

Совпадающее визуальное значение gap не означает, что детям передано `--parent-g`. Явный `core-g-*` синхронизирует вычисление ширины долей. [Доли](dimensions.md).

## P08. Адаптивные координатные объявления содержат ошибки записи

В t/m-секциях absolute встречаются отсутствующие разделители деклараций и некорректная запись рабочего `--x`. Перед использованием нестандартных угловых вариантов проверяйте computed style; не генерируйте префиксы автоматически. Это не повод отключать корректные базовые позиции. [Позиционирование](position.md).

## P09. Селектор заголовка таблицы — `core-heading-underline`

Он не называется `core-table-heading-underline`, хотя такое имя выглядело бы симметрично остальным модификаторам таблиц. Проверяйте реальные идентификаторы. [Таблицы](lists-tables.md).

## P10. Tooltip виден в структуре showcase, но его CSS закомментирован

Блок tooltip в исследованном `latest` заключён в комментарий. Заголовок/пример витрины не доказывает доступность компонента в этой опубликованной сборке. Tooltip не включён в список готовых рабочих рецептов.

## P11. Подозрительные декларации контролов

У disabled checkbox/radio значение border-color ссылается на токен полной границы (`1px solid …`), что не является допустимым значением border-color. У radio-group встречается `--color-test-primary` вместо `--color-text-primary`. В области date-input встречается ошибочная вложенная `var(var(...))`. Влияние зависит от ветки состояния и fallback; исходный Core здесь не исправлялся. [Формы](forms.md), [выбор](choices.md).

## P12. Неодинаковые словари и опечатки

`shevron` — фактическое написание семейства иконок. У некоторых адаптивных ограничений роста отсутствует `core-` в середине имени. У `core-h-170x` ссылка на не найденный базовый токен. Не исправляйте имена в разметке «для красоты» и не создавайте отсутствующие классы. [Адаптивность](responsive.md).

## P13. Короткий алиас `core-fade-pulsing` повторяется

Он также перечислен в правиле другой анимации. Точная форма `core-animate:fade-pulsing` менее неоднозначна. Transform анимации может конкурировать с позиционированием; разделяйте элементы. [Взаимодействия](interaction.md).

## P14. Hover-иерархия явно описана до трёх уровней

Это не безгранично рекурсивная система. Место сохраняется и при opacity-, и при visibility-скрытии; доступность интерактивных целей требует отдельной проверки. [Взаимодействия](interaction.md).

## P15. Глобальные эффекты и современный CSS

Изоляция reset частичная, html rem меняется глобально, переменные регистрируются глобально. Объявленная поддержка старых браузеров и матрица совместимости не найдены в доступных источниках. [Интеграция](accessibility.md).

## P16. Карта импортов ведёт на v182

В архивном `importmap.js` адреса закреплены за `core/v182/`. Для политики latest используйте [явную карту](javascript.md), а не этот загрузчик.

## P17. FormManager: хранение и отправка

Публичные поля сохраняются в localStorage и cookie, если нет `data-form-temp`. POST передаёт массив полей, не объект по именам; HTTP 500 сам по себе не вызывает ветку error. File и multiple-select требуют другой отправки. [Контракт FormManager](js-form.md).

## P18. Очередь событий и дедупликация

`EventEmitter.emit` доставляет каждый вызов с задержкой 200 мс, а не оставляет только последний. `resource` с `dedupe: true` не сравнивает аргументы. При поиске по меняющемуся запросу задавайте `dedupe: false`. [События](js-event.md), [ресурсы](js-resource.md).

## P19. Доступность и жизненный цикл JS

PopupManager не переносит начальный фокус и не блокирует через inert весь фон. CollapseManager не восстанавливает произвольное числовое значение tabindex. FormManager и PopupManager после destroy сохраняют singleton. Сценарий удаления и повторной вставки проверяйте отдельно. [Окна](js-popup.md), [коллапсы](js-collapse.md), [формы](js-form.md).

## P20. Telegram-тема не полностью совместима

Есть самоссылки custom properties и старые имена компонентных токенов. Само подключение `theme-tg.css` не гарантирует оформление всех контролов. [Темы](themes.md).

**Источники:** [Core CSS](https://cdn.sdelal.tech/core/latest/core.css) и соответствующие JS-файлы из архива `core.zip`.
