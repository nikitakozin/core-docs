# Что такое Core и где он применим

[Оглавление](../README.md) · [Правила агента](../AGENTS.md)

Core — CSS-first система композиции интерфейсов: базовые контейнеры, оформленные элементы, модификаторы и переменные. Класс может менять сам элемент, настраивать вычисление или задавать контекст для потомков. Основные правила — в [архитектуре](architecture.md) и [наследовании](inheritance.md).

## Где применять

Сайты, серверные шаблоны, кабинеты и внутренние инструменты без обязательного React и сборщика. Сетки, формы и карточки собираются из примитивов; бизнес-логика остаётся в приложении. Для встраивания в чужой интерфейс сначала проверьте глобальные правила и reset.

## Сильные стороны

Составные интерфейсы без повторения базового CSS. Согласованные шкалы, состояния контролов и оптическая типографика. Вложенные контейнеры и контекстные адаптеры: например, `core-input-box` согласует оформление находящихся внутри полей.

## Что требует внимания

Классы не полностью независимы. Дополнительная обёртка может нарушить селектор прямого ребёнка; локальная переменная не всегда пересчитает унаследованный алиас. Размеры, адаптивные префиксы и названия не везде симметричны. Перед нестандартной композицией смотрите [ограничения](pitfalls.md).

## Как пользоваться

Начните с [подключения](start.md), затем выберите компонент. Рецепты E65–E72 показывают формы, реестры и рабочие панели. Каждый пример загружается автоматически при открытии главы; ширина меняет настоящий viewport, а не только масштаб картинки. CSS приложения показан отдельно от HTML Core.

Для разработки используйте [AGENTS.md](../AGENTS.md) и тематические Markdown-файлы. В `reference/` находятся каталог явных CSS-классов, объявления токенов с областью действия и манифест исходников. Для интерактивности есть десять отдельных разделов JS.
